# Dokumen NotebookLM — SMANSALA (branch main17)
Unggah semua file di folder ini ke NotebookLM sebagai sumber:
1. `01_REKAP_FITUR.md`: daftar lengkap fitur, peran, teknologi, riwayat versi
2. `02_TOR.md`: Term of Reference / KAK
3. `03_PRD.md`: Product Requirements Document + kriteria penerimaan
4. `04_BPMN.md`: proses bisnis (dengan diagram Mermaid)
5. `05_ERD.md`: struktur data & relasi (Mermaid erDiagram)
6. `06_SLIDE_PRESENTASI.md`: naskah 16 slide presentasi
7. `07_PANDUAN_UPDATE_DEPLOY_VPS.md`: panduan update VPS ke main17 (bisa ditempel ke Gemini)

Contoh prompt NotebookLM: "Buatkan slide presentasi 16 halaman dari 06_SLIDE_PRESENTASI", "Buat ringkasan TOR 1 halaman",
"Gambarkan BPMN proses presensi wajah", "Jelaskan ERD koleksi attendance dan face_profiles".
